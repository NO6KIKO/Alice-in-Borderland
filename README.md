# Night Compound

Three.js scene of the night-time compound with a third-person walkable character.

```bash
npm install
python -m http.server 8765
```

Open http://localhost:8765 and press ▶ to walk around (WASD / Shift / Space / V).

`tools/tripo.py` generates / rigs / animates models through the Tripo API; it reads the key from `TRIPO_API_KEY` (never commit it).
